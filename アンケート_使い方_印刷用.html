QUESTIONNAIRE GUIDE

アンケート使い方

高校生版と大学生版の使い方、リンク、確認ポイントをまとめています。

高校生アンケート

Google フォーム運用 高校生用

概要

高校生向けのアンケートは、Google フォームを使って回答を受け付ける想定です。 回答はスプレッドシートに記録され、質問は4日ごとに切り替わります。

リンク

【高校生質問フォーム】 https://docs.google.com/forms/d/e/1FAIpQLScRE79oIZdHKov2RKKMpUod1tv2A7VViW2dLkHhqRDj30q3SQ/viewform
【高校生スプレッドシート】 https://docs.google.com/spreadsheets/d/1zM7ECyx-mqvbb9w6EIoCYsVssi5mIg_chcYB-qBTObc/edit?gid=263658583#gid=263658583

運用手順

  1. 高校生用フォームの URL を案内する。
  2. 回答はスプレッドシートへ自動記録される。
  3. 4日ごとのトリガーで質問が切り替わる。
  4. 必要なら更新関数を手動で実行する。

確認ポイント

  • 入力欄のラベルは「名前」
  • 回答先は高校生スプレッドシート
  • 質問は4日ごとに更新される
  • 日付ごとに回答シートが作られる

大学生アンケート

HTML Web アプリ運用 大学生用

概要

大学生版は Web アプリで運用し、授業前と授業後で URL を分けます。 管理画面で授業回を作成すると、学生ごとに質問セットが作られます。 同じ学生IDには同じ小問が重複しないようにしています。

リンク

【大学生管理画面】 https://script.google.com/macros/s/AKfycbyMPGPIwFpIJOWOAsfl88bfdLI0eHskx0I7aHITC2njjynGwXF7-TvnojgZTbdOVAg7nw/exec?page=admin
【大学生スプレッドシート】 https://docs.google.com/spreadsheets/d/1BehqLRtWNl4J3hJw3L9lpRiHdTc_ukEiqtR1nkKgW1E/edit?gid=897227944#gid=897227944

管理画面の使い方

  1. 管理画面を開く。
  2. 授業名と実施日を入れて授業回を作成する。
  3. 表示される pre / post の URL を対象者に配布する。
  4. 回答後、管理画面で集計と比較を確認する。

確認できること

  • 授業前後の合計点の変化
  • 項目ごとの増減
  • 学生ごとの前後比較
  • 同じ学生IDに同じ小問を出さない制御

シート一覧と役割

シート名 役割 補足
sessions 授業回の管理 pre / post のURLと質問セットIDを保持
question_sets 質問セットの保存 各学生IDごとの出題内容をJSONで保持
responses 回答ログ 合計点、項目点、質問文を保存
質問ログ_大学生 質問切り替えの記録 その時点で選ばれた小問の履歴
高校生版は Google フォーム運用、大学生版は Web アプリ運用です。
