# 大学生アンケート 設計書

## 1. 目的

大学生向けアンケートを、Google フォームではなく HTML ベースの Web アプリで運用する。  
授業前後で回答を取り、同一セッション内の推移を確認できるようにする。

## 2. 画面構成

### 2.1 回答画面

- URL 例: `.../exec?page=survey&session=S-...&phase=pre`
- 表示内容
  - 名前
  - 学生ID
  - 4問の質問
  - 5件法回答
- 挙動
  - URL の `session` と `phase` を元に質問セットを取得する
  - 送信時に `responses` シートへ保存する

### 2.2 管理画面

- URL 例: `.../exec?page=admin`
- 表示内容
  - 授業回の作成フォーム
  - pre / post URL の発行結果
  - 授業回一覧
  - セッション詳細
  - pre/post 平均と差分
  - 個人別の推移

## 3. URL 設計

- `page=survey`
  - `session` = 授業回ID
  - `phase` = `pre` または `post`
- `page=admin`
  - 管理画面を表示

## 4. シート構成

### 4.1 `sessions`

| 列 | 内容 |
| -- | ---- |
| created_at | 作成日時 |
| session_id | 授業回ID |
| title | 授業名 |
| event_date | 実施日 |
| note | 補足 |
| pre_question_set_id | 授業前の質問セットID |
| post_question_set_id | 授業後の質問セットID |
| pre_url | 授業前URL |
| post_url | 授業後URL |

### 4.2 `question_sets`

| 列 | 内容 |
| -- | ---- |
| created_at | 作成日時 |
| set_id | 質問セットID |
| session_id | 授業回ID |
| phase | pre/post |
| payload_json | 選ばれた4問のJSON |

### 4.3 `responses`

| 列 | 内容 |
| -- | ---- |
| submitted_at | 送信日時 |
| session_id | 授業回ID |
| session_title | 授業名 |
| event_date | 実施日 |
| phase | pre/post |
| name | 名前 |
| student_id | 学生ID |
| respondent_key | 集計用キー |
| question_set_id | 使用した質問セットID |
| q1_score..q4_score | 回答値 |
| total_score | 合計 |
| q1_text..q4_text | 質問文 |

## 5. 質問生成

- 4カテゴリは固定
- 各カテゴリで質問バンクから 1 件ずつ選ぶ
- その組み合わせを質問セットとして保存する
- セッション作成時に pre と post の両方を作る

## 6. 推移の見方

### 6.1 セッション単位

- 授業前平均
- 授業後平均
- 差分

### 6.2 個人単位

- `student_id` を優先して pre/post を突き合わせる
- 合計点の差分を表示する

## 7. 運用フロー

1. 管理画面で授業回を作成する
2. pre / post のURLを配布する
3. 学生が回答する
4. 管理画面で平均と差分を見る

## 8. 補足

- HTML ベースなので、フォームより自由に見た目や導線を調整できる
- 受講人数が増えても、回答は `responses` に蓄積されるだけなので集計しやすい
